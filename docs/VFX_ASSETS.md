# VFX и SFX: что сгенерировано и что нужно заменить

Документ описывает плейсхолдеры, которые уже лежат в проекте, и список
ассетов, которые лучше нарисовать/записать позже. Все текущие ассеты —
белые/серые с альфой, чтобы их можно было тонировать из кода.

## Быстрый старт

Перегенерировать плейсхолдеры:

```bash
./tools/generate_vfx_assets.sh
./tools/generate_placeholder_audio.sh
godot --headless --path . --import
```

Посмотреть, как это выглядит в игре:

```bash
godot --path . res://assets/scenes/game.tscn
```

## VFX-атласы

Все атласы лежат в `assets/sprites/fx/`, стороны — степень двойки.
Кадры в атласе идут сеткой, без отступов. Сейчас в `vfx_effect.tscn`
настроены такие сетки:

| Файл | Размер | Сетка | Кадр | Назначение |
|---|---:|---:|---:|---|
| `atlas_spark.png` | 64×64 | 4×4 | 16×16 | искры, искры попаданий |
| `atlas_flash.png` | 64×64 | 4×4 | 16×16 | вспышка/звезда |
| `atlas_muzzle.png` | 64×64 | 4×4 | 16×16 | вспышка выстрела |
| `atlas_pickup.png` | 64×64 | 4×4 | 16×16 | подбор металла/кометы |
| `atlas_debris_rock.png` | 64×64 | 4×4 | 16×16 | каменные осколки |
| `atlas_debris_ice.png` | 64×64 | 4×4 | 16×16 | ледяные осколки |
| `atlas_debris_metal.png` | 64×64 | 4×4 | 16×16 | металлические осколки |
| `atlas_smoke.png` | 128×128 | 4×4 | 32×32 | дым/пыль |
| `atlas_ring.png` | 128×128 | 2×2 | 64×64 | ударная волна |

### Как устроен эффект

`assets/prefabs/vfx/vfx_effect.tscn` — один универсальный эффект с шестью
слоями `CPUParticles2D`:

- `Sparks` — `atlas_spark.png`, additive, вытягиваются по направлению полёта.
- `Debris` — по умолчанию `atlas_debris_rock.png`; в рантайме подменяется на
  ice/metal.
- `Smoke` — `atlas_smoke.png`, linear-фильтр, мягкие пуфы.
- `Flash` — `atlas_flash.png` или `atlas_muzzle.png`, additive.
- `Ring` — `atlas_ring.png`, additive.
- `Sparkles` — `atlas_pickup.png`, additive.

Параметры сетки задаются в `CanvasItemMaterial_*`:
`particles_anim_h_frames`, `particles_anim_v_frames`, `particles_anim_loop`.
Если заменить атлас на другую сетку — обязательно поменять эти значения
и/или `amount`/`lifetime` в `vfx_effect.tscn`.

### Что уже есть и чего не хватает

Сейчас это **плейсхолдеры**, сгенерированные ImageMagick. Они рабочие, но
выглядят технично. Для продакшена нужны:

1. **Искры** — 16 кадров 16×16, белые/светло-серые, с альфой. Желательно
   несколько форм: точка с хвостом, короткий штрих, маленькая звезда.
2. **Вспышки** — 16 кадров 16×16, белые, симметричная звезда/крест.
3. **Muzzle flash** — 16 кадров 16×16, конус/звезда, направленная вверх.
4. **Подбор** — 16 кадров 16×16, ромб/звезда/блик.
5. **Осколки** — по 16 кадров 16×16 на камень, лёд и металл. Камень —
   угловатые куски, лёд — светлые сколы, металл — прямоугольные/острые
   обломки.
6. **Дым** — 16 кадров 32×32, мягкие белые пуфы с прозрачными краями.
7. **Кольцо** — 4 кадра 64×64, тонкое кольцо/дуга/двойное кольцо.
8. **Опционально:** спрайт-лист взрыва (например, 6×6 кадров 32×32) для
   более читаемого «бума»; сейчас взрыв собран из слоёв.
9. **Опционально:** спрайт обломка ракеты/лего-детали для разлёта при смерти.

Требования к замене:

- фон прозрачный, сам рисунок белый или светло-серый — цвет задаётся
  `modulate`/`color` в коде;
- стороны атласа — степень двойки;
- не делать кадры впритык к краю, если планируется linear-фильтр: лучше
  оставить 1–2 px запаса;
- для пиксель-арта оставлять `texture_filter = nearest` (у `Smoke` сейчас
  стоит linear — это специально);
- если меняется количество кадров, обновить `particles_anim_h_frames` и
  `particles_anim_v_frames` в `vfx_effect.tscn`.

## SFX

Плейсхолдеры лежат в `assets/sounds/sfx/` — 30 тихих WAV (10 ключей × 3
варианта). Они нужны только чтобы проверить, что пул и рандомайзер
подключены. Заменять на реальные звуки можно с теми же именами.

| Ключ | Файлы | Когда играет |
|---|---|---|
| `shoot` | `shoot_01..03.wav` | выстрел ракеты |
| `hit_rock` | `hit_rock_01..03.wav` | попадание по камню |
| `hit_ice` | `hit_ice_01..03.wav` | попадание по льду |
| `hit_metal` | `hit_metal_01..03.wav` | попадание по металлу/врагу |
| `break_rock` | `break_rock_01..03.wav` | разрушение каменного астероида |
| `break_ice` | `break_ice_01..03.wav` | разрушение льда |
| `explosion_enemy` | `explosion_enemy_01..03.wav` | смерть врага |
| `explosion_player` | `explosion_player_01..03.wav` | смерть ракеты |
| `pickup_shard` | `pickup_shard_01..03.wav` | подбор металла |
| `pickup_comet` | `pickup_comet_01..03.wav` | подбор кометы |

Для `explosion_player` в библиотеку добавлен четвёртый вариант —
существующий `assets/sounds/lego-breaking.ogg`.

### Как подключены звуки

- `assets/resources/audio/library.tres` — `AudioLibrary` с ключами.
- На каждый ключ стоит `AudioStreamRandomizer`: 3 (или 4) потока,
  `random_pitch = 1.06`, `random_volume_offset_db = 2.0`.
- `assets/scripts/managers/audio_manager.gd` — сценический пул
  `AudioStreamPlayer2D` (16 штук) + 4 UI-плеера. Новые плееры в рантайме
  не создаются.
- `Managers/Audio` добавлен в `game.tscn`.

Чтобы заменить звук:

1. Положить файлы `assets/sounds/sfx/<key>_01.ogg` (и `_02`, `_03`) с теми же
   именами.
2. Открыть `assets/resources/audio/library.tres` в инспекторе и заменить
   потоки внутри соответствующего `AudioStreamRandomizer`.
3. Либо просто заменить WAV-файлы с теми же именами — импорт подхватится
   автоматически.

Формат: OGG для музыки/длинных звуков, WAV для коротких. Для мобилок/web
лучше OGG или короткие WAV; избегать тяжёлых стерео-файлов.

## Текущие настройки «сочности»

Чтобы эффекты не выглядели как стена частиц:

- попадание: 3 искры + 1 вспышка, scale 0.65;
- тяжёлое попадание: 6 искр + 1 вспышка, scale 0.8;
- разрушение обычного астероида: 5 искр + 6 осколков + 2 дыма, scale 0.8;
- крупный астероид: 8 искр + 10 осколков + 4 дыма, scale 0.95;
- лёд: 5 искр + 6 осколков + 2 дыма, scale 0.8;
- металл: 6 искр + 4 осколка + 1 дым, scale 0.8;
- враг: 10 искр + 4 осколка + 4 дыма, scale 0.9;
- ракета: 18 искр + 8 осколков + 6 дыма, scale 1.1.

Кольцо (shockwave) пока отключено везде — оно оставалось слишком заметным
оранжевым следом. Слой `Ring` и атлас `atlas_ring.png` оставлены в сцене,
чтобы позже вернуть эффект в другом виде (например, короткую тонкую волну).

Все эффекты плавно уходят в прозрачность за 0.12–0.3 с до конца жизни.
Лимиты: до 18 активных эффектов, до 220 «частиц» в бюджете, пул на 16
эффектов с запасом до 28.

## Что ещё можно добавить позже

- Спрайт-лист взрыва для более «мультяшного» бума.
- Отдельные спрайты обломков ракеты (сейчас разлетаются лего-детали).
- Звук попадания по щиту/броне, если появятся такие типы.
- Разные цвета искр для льда/металла уже поддержаны в коде; можно добавить
  отдельные атласы, если захочется разной формы, а не только цвета.
