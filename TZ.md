# ТЗ — Closed Space Arcade

## 0. Формат

- Игра под вертикальные экраны (портрет, 9:16).
- База: 720x1280, окно для разработки: 540x960.
- Режим растяжения `canvas_items`, аспект `expand` — на других соотношениях видимая область расширяется, а не обрезается.
- Вся игровая логика привязана к реальному видимому прямоугольнику, а не к хардкоду разрешения.
- Ракета стартует в нижней трети экрана, чтобы было куда подниматься.
- Астероиды спавнятся сверху, UI — снизу.

## 1. Пули

- Пуля летит прямолинейно в заданном направлении с заданной скоростью.
- При вылете за экран более чем на 25% от его размера пуля удаляется.
- Пули создаются и переиспользуются через пул (без постоянного instantiate/free).
- Пули выпускает ракета из точки `ShootPoint`.
- Стрельба автоматическая с настраиваемым кулдауном.
- Попадание пули по цели наносит урон и возвращает пулю в пул.
- Пуля не расходуется о цели, которые не находятся в группе `damageable`.

## 2. Астероиды

### Типы

- Есть три базовых размера: большой, средний, маленький.
- Параметры типа задаются ресурсом `AsteroidType`:
  - вес при спавне;
  - скорость (мин/макс);
  - здоровье и урон;
  - уязвимость к урону и опасность для ракеты;
  - текстуры (набор вариантов, выбор случайный при спавне), масштаб, радиус коллизии;
  - дочерний тип и количество осколков при разрушении;
  - флаг «собираемый» и ценность металла.
- Спавнер создаёт только большие и средние астероиды (маленькие появляются только из осколков).
- Веса типов и частота спавна настраиваются в инспекторе.

### Спавн

- Астероиды создаются из пула.
- Частота спавна и веса типов вынесены в инспектор.
- Базовый интервал и минимальный интервал, а также джиттер настраиваются.
- Астероиды появляются за верхней границей экрана и летят вниз с небольшим горизонтальным разбросом.
- Предусмотрен лимит активных астероидов для защиты от просадок FPS.
- Вылетевшие далеко за экран астероиды возвращаются в пул.

### Разрушение

- Большой астероид при смерти распадается на 2–4 средних.
- Средний астероид при смерти распадается на 1–3 маленьких.
- Маленький астероид не распадается.
- Осколки разлетаются в стороны, наследуют часть направления и имеют собственные скорости.
- При получении урона астероид краснеет (вспышка) и возвращает цвет.
- Звук попадания по астероиду пока не добавлен — оставлено поле для назначения аудио.

### Маленькие астероиды

- Не получают урон ни при каких условиях: не добавляются в группу `damageable`, а пуля дополнительно проверяет `is_damageable()`.
- Пуля пролетает сквозь них и не расходуется.
- Не считаются опасными для ракеты.
- При приближении к ракете всасываются к ней, уменьшаются и исчезают.
- При сборе увеличивают счётчик металла внизу экрана.

## 3. Ракета

- Ракета выпускает пули.
- При столкновении с опасным астероидом разваливается на части.
- Разлёт частей выполняется по дочерним узлам с группой `lego-break` (спрайт ракеты составной и может меняться).
- Части разлетаются в стороны с поворотом, уменьшением и затуханием, затем удаляются.
- При разрушении играет звук Lego.
- Спавн астероидов после смерти ракеты останавливается.

## 4. Сложность и экран

- Чем выше ракета на экране:
  - тем сильнее трясёт ракету;
  - тем быстрее летят активные астероиды;
  - тем меньше интервал спавна новых астероидов.
- Границы перемещения ракеты привязаны к видимой области экрана.

## 5. UI

- Внизу экрана отображается счётчик металла.
- При изменении счётчика UI делает короткий «пунч» (масштаб + цветовая вспышка).

## 6. Визуал и твины

- Спавн астероидов сопровождается упругим появлением (scale tween).
- Попадание — красная вспышка и лёгкий пунч.
- Сбор металла — вращение и схлопывание.
- Разрушение ракеты — разлёт частей с вращением и fade.
- Счётчик металла — пунч при каждом сборе.
- Стиль: максимально живой и отзывчивый, «под СДВГ».

## 7. Производительность

- Пулы для пуль и астероидов.
- Заготовки создаются заранее, в рантайме по возможности не аллоцируются.
- Ограничение количества активных астероидов.
- Проверка выхода за экран не чаще фиксированного интервала.
- Видимая область экрана кешируется на кадр.
- Тяжёлые эффекты (частицы на каждом астероиде) не используются.

## 8. Расширяемость

Система должна позволять без переделки ядра добавить:

- новые типы астероидов (новые ресурсы `AsteroidType`);
- новые сцены астероидов (необязательное поле `scene` в типе);
- вражеские корабли (отдельный пул + группа `damageable` + метод `take_damage`);
- новые пулы по той же схеме (acquire/release, парковка неактивных узлов).

## 9. Открытые вопросы

- Звук попадания по астероиду не добавлен.
- Ассеты `metal_big.png`, `metal_small.png`, `energy.png` пока не задействованы — оставлены под будущие подбираемые ресурсы/энергию.
- Баланс скоростей, здоровья, частоты спавна и силы тряски — черновой, требует плейтеста.
- Нет экрана поражения/рестарта после разрушения ракеты.
